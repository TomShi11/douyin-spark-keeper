## 概述

**抖音续火花助手** 是一款专为 Chromium / Microsoft Edge 设计的自动化生产力扩展。针对抖音私信火花需每日双向交互的维系机制，本扩展在浏览器启动后自动调度后台标签页完成会话扫描与消息送达，无需人工逐一进入聊天窗口。

### 设计原则

- **静默执行 (Silent & Non-intrusive)**：全流程运行于后台非激活标签页，不抢占键盘焦点与页面视口；仅在出现阻断（未登录或安全验证）时派发系统原生通知。
- **状态真值与幂等设计 (Idempotent by Design)**：严格以页面实际渲染的聊天记录作为唯一决策源（Single Source of Truth）；任何会话在当日已有出站消息均判定已完成，绝不重复打扰。
- **改版容灾与自适应 (DOM Resilience)**：选择器解耦集中管理，内置语义匹配与拓扑结构双层兜底，支持用户在选项页以 JSON 形式即时覆写，无须重新编译代码。

## 核心架构与工程机制

```
                                [ Alarms 定时调度 ]
                                        │
                                        ▼
                            [ Background Service Worker ]
                                        │ 打开后台非激活标签页
                                        ▼
                            [ Content Script 流水线 ]
                                        │
       ┌────────────────────────────────┴────────────────────────────────┐
       ▼                                                                 ▼
[ 虚拟列表状态机 ]                                               [ 消息幂等闸门 ]
 ├─ scrollIntoView 步进                                           ├─ LCA 气泡容器定位
 ├─ scrollTop 补偿与 Event 派发                                   ├─ 倒序时序归一化 (旧->新)
 └─ 属性特征签名探测 (renderedSignature)                          └─ 纯时刻/相对时间午夜校准
                                        │
                                        ▼
                            [ 富文本状态同步与投递 ]
                             ├─ 全选选区清理
                             ├─ insertText 注入与空块压平
                             └─ Enter 模拟与出站气泡确认
```

### 1. 虚拟列表滚动与指纹探测
抖音网页端聊天列表采用虚拟滚动（Virtual Scroll）实现，视口外 DOM 节点会被实时回收与复用。
- **渲染驱动**：后台标签页中 `requestAnimationFrame` 会被 Chromium 引擎深度节流，单纯修改 `scrollTop` 无法触发组件重绘。流水线组合调用 `scrollIntoView({ block: 'end' })`、`scrollTop` 累加与显式 `scroll` 事件，并轮询特征指纹直至可视节点确认变更。
- **即时推进**：采用「边滚动边识别边发送」的就地消费策略，消除全量预扫描遗漏尾部好友的风险。
- **轻量特征签名**：指纹比对优先使用头像文件名与 `data-index` 属性，杜绝在探测轮询中触发深层 DOM 克隆。

### 2. 消息拓扑定位与时序判定
- **最近公共祖先 (LCA)**：消息气泡独立封装于各级容器内，缺乏外层统一类名。系统动态计算全部出站与入站气泡的最近公共祖先元素，准确定位完整对话流。
- **时序归一化**：抖音消息流采用倒序渲染（`data-index=0` 为最新），连续消息的时间戳仅在首条标注。系统在判定前对气泡进行时序反转（旧 → 新），确保后续消息正确继承有效日期。
- **时间语义校准**：抖音对当日数小时内的消息显示时刻（如 `09:33`），跨天会显式增加日期前缀。未带前缀的纯时刻一律归属今天；相对时间（如「3小时前」）在凌晨执行时严格执行跨午夜反算，防止昨夜会话误判为今日已发。

### 3. 富文本编辑器清理与发送模拟
输入框基于 `editor-kit` 框架构建。空状态下富文本容器自带占位空段落，直接写入会导致首行产生空换行。系统执行全选指令后通过 `beforeinput` 事件派发纯文本内容，随后移除前导空节点，完成规范的 Enter 按键事件分发。

## 安装指南

> 本扩展为开源本地扩展，未上架 Chrome Web Store / Edge 扩展商店，需以「开发人员模式」运行。

1. 前往 [**官网发布页**](https://huohua.11s.space) 或 GitHub Releases 下载最新 `douyin-spark-keeper.zip`；
2. 解压至固定的本地工作目录（浏览器每次启动均会读取该路径，请勿删除或移动）；
3. 打开浏览器扩展管理页（Edge 输入 `edge://extensions/`，Chrome 输入 `chrome://extensions/`）；
4. 开启 **开发人员模式 (Developer Mode)**；
5. 点击 **加载解压缩的扩展 (Load unpacked)**，选择包含 `manifest.json` 的解压目录；
6. 确认当前浏览器已登录抖音网页版并具备私信访问权限。

## 运行时配置

通过点击扩展图标并选择「设置」，可进入配置控制台：

| 配置项 | 默认值 | 作用域与说明 |
|---|---|---|
| **自动执行** | 开启 | 每日定时唤醒与后台执行开关 |
| **发送内容** | `🔥` | 每次自动发送的消息内容（最长 40 字符，支持 Emoji） |
| **单次上限** | `50` 人 | 单次调度处理的最大好友人数（上限 100） |
| **发送间隔** | `2000`–`5000` ms | 拟人化随机延迟区间，降低频控风险 |
| **白名单** | 空 | 强制处理列表（无火花标记亦发送），支持子串匹配 |
| **黑名单** | 空 | 绝对阻断列表（黑名单优先级最高） |
| **入口地址** | `/chat?isPopup=1` | 优先加载极简弹窗版会话，失败自动回退 `/chat` 或 `/im` |
| **选择器覆盖** | 空 | 支持在线覆盖 DOM 解析规则，无需修改扩展源码 |

## 常见问题 (FAQ)

<details>
<summary><b>1. 扩展如何保证绝不重复打扰好友？</b></summary>

系统设立了四道递进防护：
1. **每日全局闸门**：本地记录当日已执行成功的日期标记；
2. **好友身份校验**：切入会话后二次比对头像文件名，防止会话重排错位；
3. **聊天记录实时判定**：提取消息区全部气泡，只要今天已有我方发送的任何出站记录（含用户手动发送），即刻跳过；
4. **失败不重试**：任何原因导致的单人发送失败一律直接跳过，绝不在单次会话内反复重发。
</details>

<details>
<summary><b>2. 为什么有时火花仍会中断？</b></summary>

抖音火花维系规则基于双方 24 小时内的互动反馈。本扩展仅确保使用者本人在当日成功发出打卡消息；若对方在规定时间内未回复，火花仍可能自然断开。
</details>

<details>
<summary><b>3. 用户的个人隐私与账号安全如何保障？</b></summary>

- **完全本地运行**：扩展源码 100% 开源，不设任何远程采集服务器，不上传任何 Cookie、Token、好友名单或聊天内容；
- **模拟真人节奏**：出站操作间隔严格控制在 2–5 秒随机区间，符合正常交互节奏；
- **被动式执行**：内容脚本在非调度窗口期处于休眠状态，不干扰用户正常浏览网页。
</details>
